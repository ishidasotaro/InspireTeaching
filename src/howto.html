クイックスタート（30秒）

  • ＋ New Post を押す
  • タイトル と 本文 を短く（1〜2文でOK）
  • 雰囲気が伝わる 写真 を1枚選ぶ
  • トピック を選んで送信！
迷ったら タイトル は「何を教えた？」、本文 は「相手の反応／次に教えること」。

投稿の作り方

1

「＋ New Post」ボタンを押す

ヘッダー右上から投稿フォームへ。スマホならメニュー内に入っている場合があります。

2

タイトルをつける（型＋例）

型： [テーマ] を [相手] に教えた ／ [機能] の [ポイント] を一緒に練習

例1：配列の map() を教えた
例2：Flexbox の並び替えを一緒に練習
例3：Git のブランチ運用（feature→main）を説明

NG：抽象的すぎる（例「勉強した」）。数字や具体語を入れると強い。

3

本文を書く（テンプレ付き）

テンプレ：

1) 今日は 何を教えた？
2) 学習者の 反応（例：理解が深まった／発見があった）
3) 次にやること（例：filter を試す／課題に挑戦）

1〜3行でOK。箇条書きでも読みやすい。

良い例：
タイトル：配列の map() を教えた
本文：配列から別の配列を作る map() を一緒に練習。
index と value の違いでつまずいたけど、例を増やしたら反応。
次は filter() で条件抽出に挑戦！
NG例：
タイトル：勉強した
本文：いろいろ教えた。楽しかった。
→ 何を教えたかが分からない／次の行動に繋がらない
4

写真を選ぶ（伝わるカット）

  • 手元・ホワイトボード・笑顔など 「楽しさ」が伝わる場面
  • ブレ／逆光を避ける（机の上で撮ると安定）
  • 顔出しは任意。写り込みが気になるときは手元だけ
NG：画面が真っ暗／遠すぎて何が写っているか不明／個人情報の写り込み
5

トピックを選ぶ

迷ったら一番近いものを。複数候補で悩む場合は本文に補足。

HTML＆CSS ／ JavaScript ／ PHP ／ SQL ／ Git ／ その他
コピペ用テンプレ
【タイトル】
配列の map() を教えた

【本文】
今日はGitの基本について教えた。とりあえずadd,commit,pushさえできれば大体大丈夫！自分の力でcloneからmergeまで出来たら最高だよね！
（写真のフレーミング例を入れるスペース）

顔が不要なら 手元＋画面 だけでも「楽しそう」が伝わるよ。

困ったとき（トラブル対処）
  • 写真が重い → 画像サイズを小さくして再選択（長辺 1600px 目安）
  • タイトルが思いつかない → 「何を教えた？」+「誰に？」をそのまま書く
  • 内容が長くなる → 1〜3行に要約し、詳細はコメントで補足

マナー & NG例

Do（やろう）

  • タイトルは短く簡単に
  • 相手を尊重する言葉遣い
  • 学びの過程をポジティブに共有

Don't（やめよう）

個人情報、誹謗中傷、無断での顔写真の公開 はNG。

よくある質問(Q&A)

写真は必須ですか？

推奨です。写真があると「教える楽しさ」が直感で伝わります。

匿名で使えますか？

はい。ユーザー名やアイコンは任意です。

削除／編集はできますか？

このデモでは省略していますが、本番では投稿者による編集・削除を提供予定です。

投稿ガイドライン

  • ・写真は学びの雰囲気が伝わるもの（顔出しは任意）
  • ・タイトルは短くわかりやすいものが推奨です（例：gitの基本！）
  • ・本文は「何を教えた？相手の反応は？moreな点は？」の3点を書くとGood！
  • ・コメントの際の誹謗中傷等はアカウントの凍結対象です
