# InspireTeaching（IT）

コミュニティ内の「教え合い」を可視化し、学びの循環を生み出すためのWebアプリケーション。

## 1. プロダクト概要
**参照資料:** [2025夏ハッカソン プロダクト制作要件定義概要](https://docs.google.com/document/d/1edfaLgfbnaPTpiOq0bqnp1s6UHWCmd7BFAZZg6BrMPQ/edit?usp=sharing)


### お題・背景
* **ターゲット:** 教える行為自体に不安（心理的ハードル）を抱えているコミュニティメンバー
* **解決したい課題:** 他のメンバーが教えている場面を見る機会が不足しており、教え合いの文化が循環していないこと
* **CORE（プロダクトの核）:** オープンな場で「教えている様子」がわかる状態を作り、それを見た人のモチベーションを刺激して自然と教えたくなる状態にする

---

## 2. ハッカソン終了時点での課題と、この1週間での修正アプローチ

ハッカソン開発終了時、要件定義に対する実装状況を客観的に評価した結果、以下の致命的な課題（ギャップ）が特定されました。
サークル入会に向けた限られた工数（1週間）の中で、プロダクトの価値を最大化するために**スコープを絞り込み、以下の優先順位で修正・開発を実行**しました。

### ① 【最優先】複数ユーザー接続によるタイムライン共有（実装済み）
* **ハッカソン時の課題:** 複数ユーザーでの共有（同一DB/サーバー接続）が未実装だったため、自分のローカル環境でしか見えず、プロダクトの核である「オープンな場での可視化」が達成できていませんでした。
* **修正アプローチ:** データベースおよびバックエンドの挙動を修正。複数ユーザーが同時に異なる端末からアクセスした際、同一のタイムライン上に「教えた様子（投稿）」がリアルタイムで正確に共有される状態を最優先で構築しました。

### ② 【今後の改善案】コミュニティごとの可視性限定（設計・To Do化）
* **アプローチ:** 複数サーバーの構築は一週間の工数をオーバーすると判断。単一のデータベースレコードに「所属コミュニティ属性（ID）」を持たせ、表示時にフィルタリングするローコストな実装方針を策定しました（※実装は今後のフェーズとし、設計のみ記録）。

### ③ 【要件の見直し】匿名性と写真投稿の矛盾について（仕様凍結）
* **ハッカソン時の課題:** 要件定義にあった「写真投稿によるエビデンスの提示」と「心理的ハードルを下げるための匿名性」の間に、論理的な矛盾があることが判明しました。
* **アプローチ:** 今回の短期間での実装は見送りました。ユーザー名が表示される通常の仕様を維持し、コア機能の充実化を優先すべきという結論に至りました。

## 3. アプリケーション機能解説およびサイト閲覧手順

サークルメンバーの方が動作を確認する際の、各画面の仕様と機能解説です。

### 1-1. ログイン
ユーザーがログインを行う場所です。
* **テスト用メールアドレス:** [Alice@gmail.com]
* **テスト用パスワード:** [password123]
*(※認証機能およびデータベース接続を今回のブラッシュアップで修正・安定化させました)*

### 1-2. 新規登録
新規のユーザーがこのwebアプリを利用するために登録をするページです。

### 2-1. トップページ(タイムライン)
ユーザーに仲間が実際に教えている写真を見せることで参加意欲を沸かせるためのページです。
具体的には、教えている際の写真、いいね数、コメント数、投稿日時の4つを表示しています。
*(※今回の修正により、自分以外のユーザーの投稿も正確に並ぶようデータベース接続を修正しました)*

### 2-2. マイページ
自分のこのアプリでの今までの歴史を知ることができるページです。
具体的には、今までもらった総いいね数、今までの総投稿数、自分の過去の投稿を表示しています。

### 2-3. 投稿作成ページ
自分が実際に教えた内容を投稿するためのページです。
具体的にはタイトル、本文、実際に教えた写真を設定できます。
*(※各サイトへの遷移バグ・ファイルアップロード時の導線を今回の修正で最適化しました)*

### 2-4. 投稿詳細ページ
タイムラインに表示されている写真をクリックしたときに表示される投稿の詳細について記載されているページです。

### 2-5. 使い方説明ページ
このwebアプリの投稿方法について説明するためのページです。
具体的には、簡単な投稿手順、具体的な投稿手順、マナーNG例、ガイドライン、Q＆Aについて記載している静的コンテンツページです。

### 2-6. ログアウト
ユーザーがログアウトを行う場所です。
